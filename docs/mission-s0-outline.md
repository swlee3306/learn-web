# /learn S0(완전입문) 미션 10개 목차 (초안)

원칙
- 10~15분짜리로 쪼개서 "매일 1시간"이면 3~4개까지도 가능
- 새 개념은 1개씩만
- 소재는 가볍게(음악/루피/병원 상황) + 결과가 눈에 보이게

## mission-6: 버튼 클릭 = 텍스트 바꾸기
- 목표: 클릭 이벤트로 화면 글자 바꾸기
- 시간: 10
- 키워드: querySelector, addEventListener, textContent

## mission-7: 카운터 +1 만들기
- 목표: 클릭할 때마다 숫자 증가
- 시간: 12
- 키워드: number, parseInt, DOM 업데이트

## mission-8: 0으로 리셋 버튼 추가
- 목표: 상태를 초기값으로 되돌리기
- 시간: 12
- 키워드: 함수로 중복 제거

## mission-9: 조건문(10이면 축하 메시지)
- 목표: if로 조건에 따라 다른 UI 보여주기
- 시간: 15
- 키워드: if, classList, 표시/숨김

## mission-10: 랜덤 "오늘의 노래" 뽑기
- 목표: 배열에서 랜덤 1개 선택해 표시
- 시간: 15
- 키워드: array, Math.random, Math.floor

## mission-11: 입력창 받아서 인사하기
- 목표: input value 읽어서 문장 만들기
- 시간: 15
- 키워드: input, value, form, preventDefault

## mission-12: 체크박스 3개로 "준비완료" 판정
- 목표: 여러 입력 상태를 합쳐 조건 판정
- 시간: 15
- 키워드: checked, AND 조건

## mission-13: 루피 버튼(누르면 이모지/문구 토글)
- 목표: 토글 구현(켜짐/꺼짐)
- 시간: 12
- 키워드: boolean, toggle

## mission-14: 병원 호출벨(3번 누르면 '간호사 호출됨')
- 목표: 누적 횟수에 따른 분기
- 시간: 15
- 키워드: state, 조건문

## mission-15: 타이머 흉내(버튼 누르면 3..2..1)
- 목표: setTimeout으로 순차 UI 업데이트
- 시간: 15
- 키워드: setTimeout
